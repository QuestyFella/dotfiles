# Wallpapers

Not included (they're other people's art). Add your own per theme:

```
config/themes/wallpapers/<theme-name>/*.png|jpg|jpeg|heic|webp
```

or run `theme --wallpaper <image…>` to add images to the current theme.
Themes with no images get a gradient generated from their palette (`make-wallpaper.py`).
Pick one with **Hyper + G**, or `theme --next-wallpaper` for a random one.
